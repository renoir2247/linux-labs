# Лабораторная работа №4 - Git
## Описание лабораторной работы

Система контроля версий (VCS) — неотъемлемый инструмент современной разработки ПО. Данные
системы позволяют фиксировать изменения в коде, возвращаться к предыдущим состояниям,
отслеживать историю правок и эффективно организовывать командную разработку. Наиболее
распространенной распределенной системой контроля версий является Git, а крупнейшей платформой
для хостинга репозиториев — GitHub.
В отличие от традиционной работы с локальными файлами, использование Git и GitHub требует
понимания взаимодействия локального и удаленного репозиториев, механики веток (branches), а
также процедур слияния (Merge) и создания запросов на изменения (Pull Requests).

## Цель работы

Получить практические навыки работы с консольной утилитой git  и сервисом GitHub: авторизация
через SSH, создание и клонирование репозиториев, управление ветками, решение конфликтов слияния
и участие в Pull Request / Code Review.
